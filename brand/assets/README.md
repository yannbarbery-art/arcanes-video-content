# Brand assets

Logos, typographies et éléments visuels de la marque Arcanes.

- **Format préféré :** SVG (vectoriel, versionné sans restriction).
- Les PNG/JPG de ce dossier sont versionnés (exception `.gitignore`) — y garder
  uniquement des assets légers (swatches, exports de logo).
- Les fichiers sources lourds (PSD, AI...) vont dans `assets-raw/` (non versionné).
