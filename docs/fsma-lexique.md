# Lexique FSMA

> Référence vocabulaire. Arcanes est une proptech soumise à la réglementation
> FSMA : aucun contenu ne formule de conseil financier. Ce fichier fait
> autorité sur le vocabulaire à l'écran, en voix off et dans les captions.

## Termes interdits -> termes de remplacement

| ❌ Interdit (FR) | ❌ Interdit (NL) | ✅ Remplacement (FR) | ✅ Remplacement (NL) |
|---|---|---|---|
| conseil | advies | analyse | analyse |
| conseiller (verbe) | adviseren | analyser | analyseren |
| recommandation | aanbeveling | simulation | simulatie |
| recommander | aanbevelen | simuler | simuleren |
| opportunité | opportuniteit | estimation | raming |
| verdict | oordeel | résultat de simulation | simulatieresultaat |
| placement sûr | veilige belegging | scénario | scenario |
| bon plan | goede deal | donnée observée | waargenomen gegeven |

## Formulations interdites

- Toute incitation directe : « il faut acheter », « investissez maintenant »,
  « profitez-en », « ne ratez pas ».
- Toute promesse de gain : « rendement garanti », « X % assuré ».
- Toute projection présentée comme une certitude.

## Formulations conformes

- « La simulation Arcanes **estime**... »
- « D'après les données [source, date], on **observe**... »
- « Cette **analyse** présente un **scénario**, pas une garantie. »
- « **Estimation** — les résultats réels peuvent varier. »
